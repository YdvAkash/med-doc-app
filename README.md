## ✨ Features

- **📄 Document Management**: Easily upload, view, and organize medical documents, reports, and prescriptions.
- **🕒 Health Timeline**: Track your health history and medical events in a beautifully designed timeline view.
- **🤖 Smart AI Assistant**: Ask questions and chat about your medical reports to understand them better.
- **🔐 Secure & Private**: Authenticated user profiles ensuring your medical data stays safe and secure.
- **📱 Modern UI/UX**: Built with seamless animations and an intuitive, easy-to-use interface.

## 🛠️ Tech Stack

- **Framework**: [React Native](https://reactnative.dev/) & [Expo](https://expo.dev/)
- **State Management**: [Zustand](https://github.com/pmndrs/zustand)
- **Navigation**: React Navigation
- **Networking**: Axios
- **Icons**: Lucide React Native

## 🚀 Getting Started (Development)

To run the app locally on your machine:

```bash
# 1. Install dependencies
npm install

# 2. Start the Metro bundler
npm start
```
```bash
# 1. Install dependencies
npx expo run:android

```
